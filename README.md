# Cardenal Drones

Sitio web de **Cardenal Drones**: filmación, fotografía aérea y fotogrametría con drones en Gualeguaychú y Entre Ríos.

- `index.html`: página única (HTML + CSS + JS en un solo archivo).
- `img/`: logo y fotos del portafolio.
- `og-image.jpg`: imagen de vista previa al compartir el link en redes.

Publicado con GitHub Pages.
